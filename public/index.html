Regeln & Wertung
Ablauf eines Durchgangs
1. Le-Mans-Start — auf Kommando läuft ein Pilot zu seinem Modell und startet so schnell wie möglich.
2. 4 Loopings — abwechselnd rechts und links, jeweils auf einem Bein stehend ausgeführt, in der vorgegebenen Reihenfolge. Jeder korrekte Looping bringt Punkte, jeder fehlerhafte oder ausgelassene kostet Punkte.
3. Ballonphase — bis zu 3 Anflüge auf den aufgehängten Ballon. Je früher der Treffer, desto mehr Punkte. Ein Berühren der Stange gilt als Treffer.
4. Zeit-Stopp — nach der Ballonphase gibt der Pilot den Wollfaden ab; damit wird die Flugzeit gestoppt.
5. Glücksrad — am Ende dreht jeder Pilot einmal das Rad. Die gezogene Zahl × 10 wird zum Ergebnis addiert.

Punkteberechnung
400 Vorgabepunkte Startguthaben für jeden Piloten
+50 Pkt pro korrektem Looping (Richtung eingehalten)
−50 Pkt pro fehlerhaftem Looping (falsche Richtung oder ausgelassen)
+100 Pkt Ballon beim 1. Anflug getroffen
+50 Pkt Ballon beim 2. Anflug getroffen
±0 Pkt Ballon beim 3. Anflug getroffen (Stange gilt)
−50 Pkt je Fehlversuch beim 1. und 2. Anflug
−1 Pkt / Sek. gesamte Flugzeit bis Zeit-Stopp
+ Rad-Wert × 10 Glücksrad-Bonus am Ende

Vereinswertung
Das Vereinsergebnis ist der Mittelwert aller Einzelergebnisse der Vereinspiloten. Mindestens 5 Piloten müssen für einen Verein angetreten sein — fehlt ein Pilot, werden 30 Strafpunkte je fehlender Person vom Vereinsmittelwert abgezogen.

🔄 Wiederherstellung auf neuem Server
1
Node.js installieren
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash - sudo apt install nodejs
2
App-Dateien aufspielen
unzip aeroscore-deploy.zip -d /opt/ cd /opt/modellflug && npm install
3
Rclone installieren & mit demselben Account verbinden
sudo apt install rclone rclone config ← denselben Anbieter & Account wie bisher
4
Daten aus der Cloud zurückkopieren
rclone sync modellflug-backup:modellflug/ /opt/modellflug/data/
✓ Alle Wettbewerbe, Teilnehmer, Einträge & Einstellungen sind sofort wiederhergestellt
5
Server starten
RCLONE_REMOTE=modellflug-backup RCLONE_PATH=modellflug/ node server.js
6
Benutzer neu anlegen (users.json ist aus Sicherheitsgründen nicht im Backup)
Im Browser: admin / admin → Passwort sofort ändern → weitere User anlegen
⚠️ Nur einzelne Dateien wiederherstellen?
rclone copy modellflug-backup:modellflug/wettbewerb.json /opt/modellflug/data/
